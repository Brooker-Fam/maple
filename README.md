# Maple

A family newborn tracker: nursing timers, bottles, pumping, diapers, sleep, temperatures, growth on WHO percentiles, notes and questions for the doctor, photos and milestones, plus a page for mom's own medicines and check-ins. Parents log from their phones, hands-free with Siri, or from Claude and ChatGPT through its MCP server.

Built for one family (it lives at [maple.brooker.family](https://maple.brooker.family)); the code is MIT-licensed. Not medical advice.
