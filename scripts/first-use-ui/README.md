# First-use logging checks

Run `node scripts/first-use-ui/run.mjs` (or `REVIEW_BROWSER=webkit node scripts/first-use-ui/run.mjs`).

The production app is bundled into a browser fixture. Every request is intercepted at an `example.test` origin; all records and identities are synthetic. Checks cover every historical entry kind across UTC midnight, incomplete clocks and recovery in every baby logging form, explicit dates, future and reversed times, daylight-saving gaps, unsaved time drafts, manual nursing sides, care temperature, and birth details in Settings. They also cover local-midnight ranges without invented durations, second-preserving corrections across midnight and both DST changes, bath duration preservation, saved Vitamin D corrections without duplicate doses, feeding preferences, view-only access, and all kinds in the handoff recap. Today's feeding-plan card (an invented plan) covers the first feed's start with its shield and plan feed, taking turns and the due line, Do … instead on this phone, one-tap milk at the breast during a feed (once on a double tap), a missed top-up logged as that feed's, a night feed that starts with the pump, viewers, and the big action clearing the dock at 375x667 and fitting 320. `FIRST_USE_CASE` runs a matching case.
